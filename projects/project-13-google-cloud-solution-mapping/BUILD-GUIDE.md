# Build Guide — Google Cloud Solution Mapping

**Created by School of AI**

1. Define users and business outcome.
2. Extract measurable requirements.
3. Classify workload/pattern.
4. Identify data and integration systems.
5. Draw cloud-neutral architecture.
6. Mark trust boundaries.
7. Select model/data/integration patterns.
8. Compare alternatives.
9. Design failures and fallbacks.
10. Define evaluation/observability.
11. Estimate costs.
12. Map to cloud/provider services if required.
13. Create ADR.
14. Create implementation backlog.
15. Present solution recommendation.
