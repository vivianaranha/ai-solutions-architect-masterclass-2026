# Enterprise AI Solutions Architect Capstone

**Created by School of AI**

## Customer
Apex Global needs a shared AI solution for employee knowledge and service workflows across US and EU regions, integrated with CRM, service desk, documents, warehouse and enterprise identity. It follows a multi-cloud strategy and requires business-unit cost attribution.

## Required deliverables
1. executive solution brief
2. functional/NFR pack
3. workload/pattern selection
4. model strategy
5. cloud-neutral logical architecture
6. data architecture
7. production RAG design
8. agent/MCP/tool design
9. API/event integration design
10. identity/security/trust boundaries
11. AWS mapping
12. Azure mapping
13. GCP mapping
14. recommended provider/multi-cloud strategy
15. hybrid/on-prem considerations
16. evaluation/GenAIOps plan
17. reliability/scale plan
18. cost model
19. five ADRs
20. implementation handoff/backlog
21. executive proposal
22. 10-minute architecture defense

## Review-board challenges
- primary model provider outage
- 10x traffic
- EU residency restriction
- cross-tenant access attempt
- RAG quality regression
- agent unauthorized write attempt
- 25% cost-reduction demand
- request to migrate cloud/provider in 12 months
