## Solution loop
**Discover → Classify → Design → Map → Validate → Cost → Review → Handoff**

For every solution: define measurable requirements, choose the simplest viable pattern, design cloud-neutral architecture, identify data/trust boundaries, map to provider services, calculate reliability/cost assumptions, define evaluation/operations, document alternatives, and prepare implementation handoff.
