# Solution Architecture Principles

**Created by School of AI**

1. Requirements before products.
2. Simplest viable AI pattern.
3. Cloud-neutral logical design first.
4. Deterministic security controls.
5. Authorization before retrieval/tool access.
6. Failure paths before scale optimization.
7. Evaluation is part of architecture.
8. Cost per successful task matters.
9. Provider mapping must include exit strategy.
10. Implementation handoff is a first-class deliverable.
